# 動的ルートパラメータ（params）の非同期化

Next.js 15 以降、PageやLayoutコンポーネントの`params`はPromise（非同期オブジェクト）に変更された。

## 背景

Next.js 14までは`params.id`で直接文字列にアクセスできたが、Next.js 15からは将来的な最適化のために`params`が非同期的に提供されるようになった。

## 対応

`prams`を使用する前に`await`を通しておく必要がある。

## 参考リンク（技術ブログより）

[Next.js 15でparamsが非同期になった理由と対応方法(Zenn)](https://zenn.dev/h_tatsuoka/articles/3b1d3f1b445ffb)

## サンプル

```typescript
// ... imports

export default async function EventDetailLayout({
    children,
    params,
}: {
    children: React.ReactNode;
    // 型定義を Promise に変更
    params: Promise<{ id: string }>;
}) {
    // params を await して id を取り出す
    const { id } = await params;

    // 取り出した id を使用する
    const event = getEventById(id);

    if (!event) {
        notFound();
    }

    return (
        <div className="flex-1 flex flex-col">
            <EventHeader event={event} />
            {/* ここも params.id ではなく解決済みの id を渡す */}
            <TabNavigation eventId={id} /> 
            <div className="flex-1 bg-gray-50">
                {children}
            </div>
        </div>
    );
}
```
